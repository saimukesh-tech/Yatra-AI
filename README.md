# ✈️ Yatra AI — Personalized Tourism Planner

> **Plan less. Explore more. Travel your way.**

Yatra AI is a modern, intelligent tourism planning web application designed to help travelers create personalized travel experiences based on their destination, budget, interests, travel style, itinerary preferences, and transportation needs.

The current version is a **frontend-only prototype** designed to run locally using mock data.

---

## 📌 Project Overview

Traditional travel planning often requires users to search across multiple platforms for:

- Destinations
- Places to visit
- Hotels
- Transportation
- Activities
- Budget information
- Travel itineraries

Yatra AI brings these concepts together into a single, easy-to-use travel planning experience.

The application allows users to:

- Explore destinations
- Create personalized trips
- Select travel preferences
- Generate an itinerary
- View day-by-day activities
- Check budget estimates
- Explore transportation options
- Discover recommended destinations
- Find compatible travel companions
- Save and manage trips
- View and modify itinerary activities

The current application uses **mock/local data** and does not require a backend or external API.

---

# 🎯 Project Goals

The main goals of Yatra AI are:

1. Simplify travel planning.
2. Provide personalized recommendations.
3. Create structured travel itineraries.
4. Help users stay within their budget.
5. Make travel planning visually engaging.
6. Provide a modern and responsive user experience.
7. Create a foundation that can later be connected to AI and real-world APIs.
